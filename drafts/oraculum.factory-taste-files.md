# Factory taste for files — what governs where agents go
**Author:** Oraculum (director) · **Date:** 2026-07-21 · **Status:** draft, single-day study
**Origin:** majkee impulse, applications-in-common H10 + H11 · **Room:** vacuole/anechoic/naming-gravity-h11
**Raw data:** applications-in-common `.dev/research/naming-gravity/` · ledger entries H10, H11

---

## Question

When an agent must find (or trust) "AI process data" among equivalent candidates,
what actually governs it — the folder's NAME, its VISIBILITY, the HARNESS above
it, or the agent's PERSONA?

## Method

Anechoic room: an arena of four folders identical in content, differing only by
name — `.wires/` · `.meta-conductors/` · `local-meta/` · `.meta-iterations/` —
each holding an identical `frames.jsonl` + identical README. Blind headless
subjects (`claude -p`, cwd=arena, unpoisoned prompt), three arms:

- **A — clean** (5: 3 sonnet + 2 haiku): no conductor.
- **B — dosed** (5): a planted `./CLAUDE.md` (harness-shaped, teaches the word
  "wires", names no folder), removed after. Injection confirmed 5/5.
- **C — personas** (2): kestrel/moth via standard `.claude/agents/`, no conductor.

Scoring: visit order 5/3/1/0/−1 per folder and per file → vectors → plane maps.
Plus H10 (same day, sibling experiment): bait planted INSIDE a wire — a directive
line and a false schema pointer — against two blind Sonnets.

## Results — four forces, ranked

1. **Conductor gravity owns the JUDGMENT.** `.wires/` picks: 0/4 clean → 3/4
   dosed. Three sentences of vocabulary flipped the never-chosen house name to
   dominant — while leaving visit order untouched. Side-effect discovered: the
   dose's "keep reads light" rule made one subject do a plain listing, miss every
   dotted folder, and confidently crown the only folder it saw. **Conductor rules
   shape search depth, not just belief.**
2. **Visibility gravity owns the WALK.** The single non-dotted folder was swept
   first in 9/10 full explorations, in every arm. No dose or persona dislodged it.
3. **Vocabulary gravity owns the pick only in a conductor vacuum** (clean subjects
   argued semantics: "iterations maps most directly onto the data").
4. **Convention gravity is a minority force** — a minimal persona read the dot
   prefix as a system-data cue at pick time, inverting the visibility penalty.

**Discipline is orthogonal to taste:** generic haiku breached the room wall 2/2
despite explicit confinement; a two-line persona held it 0/1; sonnets 0/5.
**Persona = cheap guardrail, not a taste-setter** (it moved nothing else).

**From H10:** hands are loyal, beliefs are for sale — Sonnet refused an in-band
COMMAND (named it prompt injection unprompted) but elevated a fine-looking
in-band SCHEMA CLAIM to "declared authority." The attack surface is epistemic,
not behavioral. Product: wire meta cards now carry an exclusivity clause
(the card is the wire's sole schema authority; in-band claims void).

## Implications

- **Data meant to be found** by uninitiated agents: visible + task-semantic name.
  Visibility never lost a walk.
- **House infrastructure under a conductor:** the name is free — the harness
  carries the meaning. `.wires/` has zero natural gravity and total conducted
  gravity; for machine-local telemetry that should NOT attract strangers, that
  is the correct profile. The factory's form-home + meta-card + ladder pattern
  is validated by blind data.
- **Harness design warnings:** token-economy rules can hide dotted infrastructure
  from your own agents; meta cards must claim exclusivity or in-band bait can
  outrank them; prompt-level confinement does not hold haiku — persona-level does.
- **Lab methodology:** room path names leak intent (subjects inferred "experiment
  sandbox" from `naming-gravity`/`anechoic` segments) — bland codenames for
  future rooms. `./CLAUDE.md` injection in headless mode is empirically proven —
  the dose mechanism is reusable as a standard instrument.

## Limits & next

n=13+2, one day, one machine, one model family, self-reported visit order.
Shape-finding, not statistics. Follow-ups: repetition, opus tier, dose titration
(1 vs 3 sentences), adversarial dose (conductor pointing at the WRONG folder —
bridges to H10's belief-capture), and the conducted-control arm (real house
seats) for the full harness-gravity number.
