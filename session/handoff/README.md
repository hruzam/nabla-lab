# session/handoff — courier files + wake docs

`convention: flag lock 16 · gaveled 2026-07-09 · keep this folder self-explanatory`

- Everything handoff-shaped lives **here**, never in `session/` root:
  courier files `FOR-<addressee>.*` and reincarnation wake docs `handoff.<agent>.<date>.md`.
- `archive/` — delivered or superseded items move there.
  *Delivered* = the addressee holds the authoritative copy (e.g. temple `_mail`);
  the copy here becomes historical record.
- Exactly **one live wake doc per agent**; `session/pulse.md` names it.
